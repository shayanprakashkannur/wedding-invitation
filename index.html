Free GitHub Pages Hosting & Customization Guide

1. How to Host on GitHub Pages (100% Free):

  1. Create a free account on GitHub.com.
  2. Create a new public repository (e.g., named wedding-invitation).
  3. Upload this file into your repository and name it strictly index.html.
  4. Go to Settings > Pages, select main branch, and click Save.
  5. Your site will be live at https://yourusername.github.io/wedding-invitation/!

2. How to Swap Photos with Real / Cartoon Photos:

In the code, search for <img src="..."> or cartoon SVG cards, and replace the placeholder URLs with:

  • Your own uploaded photos inside your repository (e.g. img/couple1.jpg).
  • AI-generated cartoon avatars from tools like Midjourney, ToonMe, or ChatGPT DALL-E.

3. Receive RSVP Responses Directly:

By default, RSVPs are saved in the visitor's browser local storage. To get emails directly:

  • Sign up on Formspree.io or create a Google Form.
  • Replace the form action URL in the code with your Formspree endpoint.
